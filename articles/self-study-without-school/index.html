管理業務主任者試験の資格学校なしの独学

管理業務主任者試験は、資格学校・通信講座なしでも受験・合格が可能です。学校のカリキュラムの代わりに、マンション管理業協会の要項と公式テキスト目次を月次計画の骨格に据えます。令和8年度は試験日2026年12月6日（日）13:00〜15:00、50問・120分・5出題分野、受験手数料8,900円（非課税・要項で再確認）です。本記事では最小教材構成、週10時間の復習型、2週間試行から8か月計画への拡大、直前1か月の解き直し集中を表にまとめます。演習正答率を2週間ごとに記録すれば、独学でも進捗が見えます。

この記事の要点

本記事を読むと、資格学校・通信講座なしで合格に必要な学習の組み立て方が分かります。

  • テキスト1＋問題集1
  • 週10時間×8か月
  • 日曜は解き直し
  • 正答率を2週間記録
  • 要項が正本

1独学前に要項と資格を確認

資格学校なし独学の前提。

  • マンション管理業協会要項での受験資格確認と
  • 試験日から逆算した週次学習時間

| 確認項目 | 内容 |
| --- | --- |
| 受験資格 | 要項の区分表と自分の経歴を照合 |
| 試験日 | 12月6日（日）から逆算 |
| 出題範囲 | 5出題分野・公式テキスト目次 |
| 申込 | 手続き用カレンダーを別管理 |

学校案内より要項原文を優先し、不明点は申込前にマンション管理業協会へ問い合わせてください。初日の手順は「独学の始め方」記事の4項目表と揃えると迷いません。

2最小教材構成

学校のテキスト＋問題集＋模試に相当する最小セットです。

| 教材 | 役割 |
| --- | --- |
| 公式テキスト1冊 | 条文・体系理解（受験年度版） |
| 問題集1冊 | 分野別＋通し模試 |
| 当サイト演習 | 分野別・一問一答・用語解説 |
| 追加参考書 | 解き直しが回るまで買わない |

3冊以上に増やすより、1冊を2周する方が得点に直結します。選定基準は「テキストの選び方」、過去問の順番は「過去問の使い方」で確認してください。

3演習10問で現在地を測る

開始2週目に演習10問で現在地を記録します。

| 正答率 | 次の行動 |
| --- | --- |
| 30〜50％ | 正常範囲・同章を継続 |
| 40％未満 | テキスト該当章を読み直し |
| 60％以上 | 次章へ（解き直しは3日後） |
| 記録 | 分野別1行メモを必須 |

学校の模試と違い、自分で正答率を付ける習慣が重要です。2週間ごとに同じ10問を解き直し、伸びがなければ週時間か章の進め方を修正します。

4週10時間の復習型

独学の復習は日曜固定が、学校の授業復習に相当します。

| 曜日 | 内容（目安） |
| --- | --- |
| 月〜金 | テキスト半章＋演習5問 |
| 土 | 新規演習10問 |
| 日 | 間違い解き直し＋用語5語 |
| 週合計 | 10時間（平日1.5h・休日4h） |

週10時間を8か月続けるのが学校なし独学の基本形です。繁忙期は週7時間に下げ、翌月に巻き返す計画を「学習計画の立て方」で組み込んでください。

5直前1か月の絞り込み

直前1か月は新規インプットを止めます。

1. 間違いノート解き直しを週の60％に配分
2. 通し模試を50問（または45問）120分で月2回
3. 弱点2分野に演習時間の70％を集中
4. 会場確認は要項と「試験日程」で試験2週間前までに完了
5. 12月6日（日）2週間前は睡眠7時間を固定

学校の直前講座の代わりに、弱点分野の演習解き直しを優先してください。筆記用具・受験票の確認は「試験当日の持ち物」記事と要項で前日までに済ませます。

6よくある質問

資格学校なし独学は何から始めればよいですか？
要項確認→公式テキスト第1章→演習5問→用語5語の順です。2週間で演習10問の正答率を記録し、8か月計画に拡大してください。初日のチェックリストは「独学の始め方」記事で表に整理しています。通信講座がなくても、週10時間と日曜解き直しがあれば十分運用できます。
公式情報はどこで確認しますか？
試験日・受験資格・出題範囲はマンション管理業協会の受験要項が正本です。学校の案内や非公式まとめは参考程度にし、数値・日程・合格基準は要項PDFで必ず上書き確認してください。受験手数料8,900円・申込締切は「試験日程」記事と併せて、学習用カレンダーと手続き用カレンダーを分けて管理すると混乱しにくくなります。
独学でも資格学校なしで合格できますか？
はい。多くの受験者が学校なし独学です。公式テキスト1冊＋問題集1冊＋当サイト演習＋週10時間×8か月で十分戦えます。2週間ごとの正答率記録と弱点2分野集中を続け、過去問の順番は「過去問の使い方」でテキスト先行の型を確認してください。
