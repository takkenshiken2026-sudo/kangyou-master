管理業務主任者試験の形式（50問・120分・5出題分野）

管理業務主任者試験の形式は、一般社団法人マンション管理業協会の受験要項の「試験の概要」「試験科目」が正本です。令和8年度は午後2時間（13:00〜15:00）、4肢択一・マークシート、通常50問・5出題分野（マンション管理士試験合格者は適正化法5問免除で45問）が公表例です。CBT（コンピュータ試験）ではなく、会場での紙のマークシート受験が標準です。本記事では要項から抜き出す4項目と、演習・模試を本番条件に近づける手順を表に整理します。数字は必ず https://www.mankan.or.jp/ の要項原文で照合してください。

この記事の要点

本記事を読むと、本番の解答方式と120分の時間配分の前提が分かり、分野別演習から50問（または45問）通し形式へ段階的に移せます。

  • 4肢択一・マークシート
  • 50問・120分（免除45問）
  • 5出題分野
  • CBTではない
  • 模試は本番条件

1要項で確認する形式4項目

試験形式の正本はマンション管理業協会の受験要項です。次の4項目を模試ノートの表紙に写します。

| 項目 | 令和8年度の公表例（要項で再確認） |
| --- | --- |
| 試験時間 | 12月6日（日）13:00〜15:00（120分） |
| 解答方式 | 4肢択一・マークシート（紙） |
| 出題範囲 | 5出題分野（委託契約・会計・維持修繕・適正化法・その他） |
| 問題数 | 50問（マン管士合格者は適正化法5問免除で45問） |

CBTやタブレット受験の記述は管業試験の標準形式ではありません。他資格の形式と混同しないよう、要項PDFの試験方法章だけを正本にしてください。

24肢択一とマークシートの練習

4肢択一では、条文の理解に加えて「消去の順番」と「マークの正確さ」が得点に効きます。

| 練習 | 目的 |
| --- | --- |
| 記入練習2回 | 枠ずれ・二重マーク防止 |
| 1問約2.4分の目安 | 120分で50問に届く配分（45問はやや余裕） |
| 見直し5分 | 未解答・マークミス確認 |
| 分野別→通し | 段階的に本番形式へ |

  • 演習は最初から通し50問より
  • 分野別10問で正答率を記録し
  • 5出題分野を一通り終えてから要項どおりの問題数で通し模試に入る流れが安定し

35出題分野と問題数の読み方

出題は5分野です。各分野の出題数・配点は要項の科目表と公式テキスト目次で揃えます。

| 分野 | 学習の入口 |
| --- | --- |
| 委託契約 | 管理委託契約の条項・報酬 |
| 会計 | 管理費・修繕積立金・収支報告 |
| 維持修繕 | 計画・工事・重要事項説明 |
| 適正化法 | マン管士合格者は出題免除（要項確認） |
| その他管理事務 | 総会・規約・記録 |

  • 45問受験でも120分は同じため
  • 時間配分はやや余裕が出ますが
  • 他4分野の演習量は50問受験者と同様に確保してください

4模試・演習を本番形式に合わせる

試験2か月前からは、本番に近い条件で通し演習を月1回入れます。

| 条件 | 内容 |
| --- | --- |
| 問題数 | 50問（5問免除時は45問） |
| 時間 | 120分タイマー |
| 記録 | 分野別正答数・時間切れ数 |
| 復習 | 誤答のみ1週間後に解き直し |

当サイトの実践演習は分野タグ付きで解けます。通し模試の翌日は新規学習を増やさず、誤答理由の分類（知識不足・時間不足・ケアレス）に30分だけ使うと直前の負荷を抑えられます。

5形式で混同しやすい点

管業試験はCBTではない

管理業務主任者試験は要項どおりマークシートの紙試験が標準です。他資格のCBT対策記事と混同しないでください（当サイトのCBT記事は参考用）。

マン管士試験の形式と別

マン管センター実施のマンション管理士試験は別試験です。問題数・分野数・手数料はそれぞれの要項で確認してください。

5問免除＝時間短縮ではない

45問でも試験時間は120分です。1問あたりの配分が変わるだけで、他4分野の演習量を減らしすぎないよう注意してください。

受験手数料は問題数と無関係

50問でも45問でも、受験手数料8,900円（非課税）は要項どおりです。

6よくある質問

管理業務主任者試験は何問・何分ですか？
令和8年度の公表例では、通常50問・120分・4肢択一・マークシートです。マンション管理士試験合格者が適正化法5問免除を受ける場合は45問・120分となります。出題は5分野からです。試験日は12月6日（日）13:00〜15:00、最新の問題数・合格基準は必ずマンション管理業協会の受験要項で再確認してください。
マークシートの練習はいつから始めますか？
分野別演習で正答率が安定してきた段階（目安：学習開始2か月後）から、記入練習と50問120分の通し演習を月1回入れるのがおすすめです。試験1か月前は通し回数を増やし、見直し5分を必ず確保してください。45問受験の場合も、マークシートの枠ずれ防止の記入練習は同様に必要です。
CBT対策が必要ですか？
管理業務主任者試験は、要項どおり会場でのマークシート（紙）受験が標準です。CBT専用の対策は不要で、4肢択一の読み方と120分の時間配分・マーク精度に集中してください。他資格と並行学習している場合は、管業の形式は本記事と要項だけを正本にし、問題数50問・手数料8,900円で区別してください。
