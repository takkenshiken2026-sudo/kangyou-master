管理業務主任者試験の試験制度の変更点

管理業務主任者試験は要項改定で範囲・合格基準・手続きが年度更新されることがあります。たとえば2026年6月4日要項30分から9月1日PDF差分15分を確認し、12月6日（日）13:00〜15:00まで約25週、令和8年度は50問120分・手数料8,900円です。

この記事の要点

本記事を読むと、制度変更の確認手順が分かり、6/4五章から9/1差分、10月改定章40問まで設計できます。

  • 6/4五章30分
  • 9/1差分15分
  • 8,900円
  • 8/3申込
  • 11/29再確認

1誤解：去年と同じで申込だけ

制度変更の誤解は去年要項の使い回しです。たとえば2025年手数料表記をそのまま使うと、2026年8,900円要項1行で上書き確認が必要です。体験記の日程・形式も年度確認が定番です。

項目確認
手数料8,900円
問題数50問
時間120分
形式要項

具体例として、6月4日30分五章読みが8か月独学の索引になります。

26/4・9/1：要項差分3点チェック

改定確認は6/4骨格＋9/1差分15分です。

  • 例えば6月4日21:00に五章を読み
  • 9月1日に科目・範囲・合格基準の3点を比較し
  • 1文字変われば5分野1枚を更新する流れが定番
日行動
6/4五章30分
6/1PDF保存
9/1差分15分

更新なしでも「9/1確認済み」1行メモを残してください。8/3申込・9/30締切は要項読み直後にカレンダー別色登録します。

3試験改定と合格後手続きの分離

試験改定と合格後手続きは別フォルダです。

  • たとえば9/1「登録手続」変更があれば
  • 学習メモとは分離し
  • 12/6合格後に閲覧
  • 8月申込8
  • 900円PDFは手続フォルダに保存し
種別時期
出題9/1
申込8/3〜
試験12/6
登録合格後

具体例として、混在すると改定章10問が1週遅れやすいです。5出題分野の学習表と手続フォルダは分けて管理してください。

4計画遅延：残り25週で48％70％

計画遅れ時は弱点2分野に絞ります。例えば9月開始で残り12週なら、会計48％70％＋解き直し60％を優先し、新規5分野一気は非推奨です。

  • 残り12週：弱点2分野
  • 48％：70％配分
  • 通し：月1回
  • 11月：30問
  • 9/1：差分必須
  • 11/29：再確認

800問追加よりミス30問90％が遅延時の得点源です。9/1差分15分は遅延時でも省略せず「更新なし」記録を残してください。

5情報優先：要項＞公表＞体験記

情報源優先順位は要項が最上位です。

  • たとえば要項から公表資料
  • 公式テキスト
  • 体験記の順で参照し
  • SNSは要項1行検証後のみ使う流れが定番

1. 6/4五章
2. 9/1差分
3. 8/3申込
4. 11/29再確認
5. 12/6 13:00
6. 48％→70％

12/5は新規制度読み停止、配分紙1行と受験票確認だけにしてください。手数料8,900円明細は8月申込PDFで再確認します。

6よくある質問

ネットの体験記だけで改定を判断してよいですか？
いいえ。令和8年度要項PDFが正本です。具体例として、6月4日五章30分から9月1日差分15分を確認し、体験記の改定話は要項1行0/1検証後のみ参照してください。48％分野70％配分は体験記より通し50問データを優先してください。正本 https://www.mankan.or.jp/ を6月4日にブックマークしてください。
制度変更がなくても要項確認は必要ですか？
はい。9/1・11/29の2回見直しが定番です。たとえば9/1「変更なし」1行メモを残し、手数料8,900円・50問120分・12/6 13:00を再確認してください。更新なし年度も確認記録を残すと8月申込時に安心です。Web9/30・郵送8/28消印も同日カレンダー登録してください。
制度変更対応は独学でもできますか？
はい。6月4日五章30分と9月1日差分15分は個人で可能です。具体例として、差分なしなら通常月2分野40問、差分ありなら改定章10問/週で対応できます。通信講座がなくても8/3申込・9/30締切のカレンダー登録で十分です。11/29受験票確認日に要項1行再チェックを固定してください。
