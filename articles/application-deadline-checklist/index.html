管理業務主任者試験の申込締切前チェックリスト（令和8年度）

管理業務主任者試験の申込は、締切直前にミスが集中しやすい手続きです。令和8年度の公表例ではWeb申込は9月30日（水）まで、郵送は8月28日（金）消印、試験日は12月6日（日）13:00〜15:00、50問・120分、受験手数料は8,900円（非課税）です（いずれも要項で再確認）。本記事では締切7日前・3日前・当日の3段階チェックリストと、資格・写真・5問免除・決済・受験票照合を表にまとめます。正本は https://www.mankan.or.jp/ の受験要項であり、非公式の代行案内は使わないでください。

この記事の要点

本記事を読むと、申込締切前に漏れなく確認すべき項目がチェックリスト形式で分かり、締切直前の申込ミス・決済エラーを防げます。

  • 要項が締切の正本
  • Web9月30日・郵送8月28日消印
  • 手数料8,900円＋Web297円
  • 3段階チェック
  • 45問表記を要確認

1締切前の最優先（受験資格）

締切前の最優先は受験資格です。マンション管理業協会要項の区分表で該当行を特定し、実務・学歴・管理組合員歴などの日数をメモに起こします。

| 確認項目 | 作業 |
| --- | --- |
| 該当区分 | 要項表と経歴が一致 |
| 証明書類 | 発行に時間がかかるものは先に依頼 |
| 問い合わせ | 疑問は決済前に協会へ |
| 試験日 | 2026年12月6日（日）— 要項で再確認 |
| 学習 | 5出題分野の演習は手続きと並行可 |

資格不明のまま8,900円を支払うと受験無効となるおそれがあるため、「受験資格の確認」で区分と書類を終えてから本チェックリストの決済項目へ進みます。

2締切日時のメモ（Web・郵送）

令和8年度の公表例で。

  • Web申込は2026年9月30日（水）まで
  • 郵送は8月28日（金）消印が目安

日付だけでなく要項の受付終了時刻まで確認します。

| 方法 | 締切の例（要項で上書き） |
| --- | --- |
| Web | 9月30日・終了時刻まで |
| 郵送 | 8月28日消印（必着か消印か要項確認） |
| カレンダー | 締切7日前・前日・当日午前の3リマインド |
| 試験日 | 12月6日（日）13:00〜15:00 |

  • Webと郵送を混同しないよう
  • 選んだ方法をメモの見出しに大きく書き
  • 「試験日程（令和8年度）」と1枚のカレンダーにまとめ

3写真・氏名・受験地の最終確認

締切3日前までに、入力内容と添付データを最終確認します。

| 項目 | チェック |
| --- | --- |
| 写真 | 背景・サイズ・ファイル形式（要項規格） |
| 氏名・住所 | 身分証明と表記ゆれがないか |
| 受験地 | 当日の移動・宿泊が現実的か |
| 5問免除 | 区分選択と証明書類の同封・提出 |
| 連絡先 | メール・電話が受信可能か |

会場の個別名称は受験票到着後に確定するため、申込時点では受験地の選択ミスに集中します。アクセスの詳細は受験票と公式案内で、試験2週間前までに確認してください。

4受験手数料と決済（8,900円）

申込と同日中の決済を原則にします。金額・方法は要項と申込画面が正本です。

| ステップ | ミス防止 |
| --- | --- |
| 金額 | 8,900円（非課税）と表示が一致するか |
| Web合計 | 297円（税込）事務手数料を含めた残高確認 |
| 決済手段 | 要項で許容される方法か |
| 完了画面 | スクリーンショット・PDF保存 |
| 5問免除 | 問題数減でも手数料条文は要項どおり |

決済エラー時は同じ操作を繰り返さず、要項の問い合わせ先に状況を伝えます。締切当日の混雑を避けるため、9月中旬までに写真と支払いまで済ませる計画が安全です。

5印刷用チェックリストと申込後

締切前に次をすべて確認します。

□ 受験資格区分を要項表で特定した
□ Web9月30日／郵送8月28日消印のどちらか一方に固定した
□ 写真・氏名が要項・身分証と一致
□ 受験手数料8,900円（＋Web297円）の決済完了
□ 5問免除該当者は証明書類を期限内に提出した
□ 受験票の氏名・受験地・45問／50問を照合した

すべてにチェックが入ったら、学習は5出題分野の弱点演習に切り替えます。

6よくある質問

令和8年度の申込締切はいつですか？
公表例ではWeb申込は2026年9月30日（水）まで、郵送は8月28日（金）消印が目安です。締切日に加え、要項の受付終了時刻（何時まで）も必ず確認してください。試験日は同年12月6日（日）、受験手数料は8,900円（非課税）です。Webでは事務手数料297円（税込）が別途かかるため、9月中旬までに写真・決済を済ませることを推奨します。
締切直前に忘れがちな確認項目は何ですか？
受験資格の該当区分、写真データの規格、氏名表記の一致、受験地の選択、8,900円の決済完了、マン管士合格者の5問免除申告と証明書類です。Webと郵送の締切を混同しないよう、選んだ方法だけをカレンダーに登録してください。申込完了後は受験票の問題数表記と開始時刻を早めに確認し、学習は分野別演習の正答率記録に戻すとスケジュールが安定します。
申込完了後、最初に確認すべきことは何ですか？
受験票に記載の氏名・受験地・45問か50問かが申込内容と一致しているかを最優先で確認します。決済控えと完了画面は保存し、問い合わせ時にすぐ出せるようにしてください。会場アクセスは「受験地・会場の確認」記事と要項で、試験2週間前までに照合し、学習は正答率50％未満の分野2つに週の時間の70％を配分すると得点管理が続きやすいです。
