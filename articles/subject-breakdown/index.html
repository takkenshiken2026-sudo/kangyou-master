管理業務主任者試験の5出題分野と学習配分（科目構成の見方）

管理業務主任者試験は50問・120分・4肢択一のマークシートで、出題は5出題分野（委託契約・会計・維持修繕・適正化法・その他管理事務）に分かれます。令和8年度は試験日2026年12月6日（日）13:00〜15:00、受験手数料8,900円（非課税・要項で再確認）です。本記事では一般社団法人マンション管理業協会（https://www.mankan.or.jp/）の要項と公式テキスト目次を正本に、分野ごとの学習時間の割り方・演習記録の付け方・直前の絞り込みを表にまとめます。マン管士合格者の45問試験では適正化法が出題されないため、配分表は50問用と45問用で分けて読んでください。

この記事の要点

本記事を読むと、5出題分野の全体像と自分の弱点分野への時間配分が分かり、分野別演習の記録を学習計画に反映する方法が整理できます。

  • 5出題分野は要項が正本
  • 50問・120分・マークシート
  • 分野別正答率で配分
  • 45問は適正化法除外
  • 目次1枚と演習記録

15出題分野の早見表（要項ベース）

科目構成・出題範囲の正本は、マンション管理業協会の令和8年度受験要項と公式テキスト目次です。

| 出題分野 | 内容の目安（要項で再確認） | 学習メモ |
| --- | --- | --- |
| 委託契約に関する法律 | 管理委託契約・権限・報告等 | 条文と事例の往復 |
| 会計 | 管理費・会計処理・監査等 | 計算と制度のセット |
| 維持修繕 | 計画・積立金・工事手続等 | 数値と手続の確認 |
| 適正化法 | マンション等の管理の適正化 | 45問受験者は出題なし |
| その他管理事務 | 総会・規約・実務判断等 | 横断ノートに統合 |

各分野の設問数は要項の出題範囲表で確認してください。非公式の「均等10問」まとめだけで計画を立てないでください。

2学習時間の配分の目安

配点の公表形式は年度で異なるため、個人計画は演習の正答率と所要時間で補完します。

| 分野群 | 時間配分の目安（50問受験） | 記録の仕方 |
| --- | --- | --- |
| 委託契約・会計 | 全体の30〜35％ | 週次で10問演習 |
| 維持修繕・その他 | 各15〜20％ | ミス理由を3分類 |
| 適正化法 | 10〜15％（45問なら軽読み） | 用語集で骨格確認 |
| 弱点 | 正答率40％未満に週60％ | 解き直しを優先 |

初学者は委託契約→会計→維持修繕の順で1周し、2週間ごとに計画を見直す手順は「学習計画の立て方」でも表にしています。

345問試験での配分の違い

マンション管理士試験合格者の適正化法5問免除（45問・120分）では、出題されない分野の学習時間を他4分野へ振り替えます。

| 区分 | 問題数 | 配分の考え方 |
| --- | --- | --- |
| 通常 | 50問・120分 | 5分野すべてに演習 |
| 5問免除 | 45問・120分 | 適正化法タグの新規演習を減らす |
| 共通 | 120分 | 1問あたり約2分40秒の目安 |
| 登録後 | — | 適正化法は実務で再登場 |

免除の手続は「免除制度」、試験形式の数字は「試験形式の概要」で要項どおりに確認してください。

4演習・通し模試との対応

科目構成を計画に落とすには、当サイトの実践演習（5出題分野別）と記録が必要です。

| 段階 | 作業 |
| --- | --- |
| 初級 | 5分野をそれぞれ10問ずつ1周 |
| 中級 | 50問（または45問）120分の通し演習を月1回 |
| 記録 | 分野別正答率を月1回更新 |
| 直前 | 弱点2分野に時間60％・新規年度問は4週前で停止 |

出題範囲の章立ては「出題範囲の概要」、過去問の段階配分は「過去問の使い方」でテキスト→分野→通しの順を確認できます。

5科目構成で混同しやすい点

マン管士試験の7分野と同一ではない

マンション管理士試験は7分野・別要項です。管業の5出題分野名をそのまま流用しないでください。

「配点10点×5」は要項で確定しない

設問数の内訳は受験要項の出題範囲表が正本です。体験談の数字だけで弱点判断しないでください。

45問＝全分野が簡単ではない

適正化法が出ない分だけ他4分野の密度が上がるイメージで、通し演習は45問120分で練習してください。

テキスト目次と要項の章名

表記ゆれがある年度は、目次1枚に要項の正式名称を併記すると演習タグと一致しやすくなります。

6よくある質問

5出題分野は毎年変わりますか？
出題分野の名称・範囲は、マンション管理業協会の最新受験要項と公式テキスト改版情報が正本です。大きな改定がある年度は新旧要項を比較し、改定章に演習を追加してから通し模試に戻してください。非公式の頻出まとめは参考程度に留め、要項PDFで必ず確認してください。
どの分野から勉強を始めるのがよいですか？
初学者は委託契約に関する法律と会計から入り、その後に維持修繕・その他管理事務・適正化法の順で1周する進め方が定番です。すでに管理会社勤務の方は、実務に近い分野から着手し、分野別10問の正答率が低い章を次の2週間の重点にしてください。全体の週次計画は「学習計画の立て方」でも表形式で整理しています。
分野別の正答率は何％を目標にすればよいですか？
合格基準は要項の相対評価等で決まるため、絶対的な「合格ライン％」を記事で固定することはできません。個人計画では分野別40％未満を弱点として演習量を増やし、通し50問（または45問）模試で時間切れがないかを併せて見てください。得点の読み方は「合格点と得点の見方」でも要項ベースで整理しています。
