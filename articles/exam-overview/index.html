管理業務主任者試験の概要（令和8年度の確認手順）

管理業務主任者試験は、マンション管理の実務に必要な知識・能力を評価する年1回の学科試験です。令和8年度は試験日が2026年12月6日（日）13:00〜15:00、50問・120分・4肢択一・マークシート、受験手数料は8,900円（非課税・要項で再確認）と公表されています。本記事では一般社団法人マンション管理業協会（https://www.mankan.or.jp/）の受験要項を正本として、初めて調べる人が最初にメモすべき5項目と、5出題分野の学習を当サイトの演習・用語解説と組み合わせる順番を表にまとめます。数字・締切は年度で変わるため、学習開始前に必ず最新要項を開いてください。

この記事の要点

本記事を読むと、管理業務主任者試験の位置づけと5出題分野、要項で確認すべき日程・手数料・合格基準の見方が分かり、次に読むべき記事（試験日程・学習計画・過去問）へ進める状態になります。

  • 正本はマンション管理業協会要項
  • 令和8年度試験日12月6日（日）
  • 50問・120分・5出題分野
  • 受験手数料8,900円
  • マン管合格者は45問

1管理業務主任者試験の位置づけ

管理業務主任者試験は、一般社団法人マンション管理業協会が実施するマンション管理の実務に必要な知識・能力を評価する試験です。合格すると管理業務主任者として登録・更新の手続きに進み、管理組合・管理会社の現場で求められる法令・実務の理解を示す指標になります。

| 項目 | 内容（要項で再確認） |
| --- | --- |
| 実施回数 | 年1回（学科試験） |
| 試験時間 | 120分（令和8年度は13:00〜15:00） |
| 出題形式 | 50問・4肢択一・マークシート |
| 出題範囲 | 5出題分野（要項の科目表） |
| 正本 | 令和8年度受験要項（https://www.mankan.or.jp/） |

マンション管理士試験（マン管）とは別試験です。マン管合格者の適正化法5問免除は管業試験だけの制度なので、マン管の日程・手数料の記事をそのまま流用しないでください。

2要項で最初にメモする5項目

要項を初めて開いたら、次の5項目を1枚のメモにまとめます。下表は執筆時点の公表例です。申込前に要項で必ず上書き確認してください。

| 項目 | メモの例 |
| --- | --- |
| 試験日 | 2026年12月6日（日）13:00〜15:00 |
| 申込締切 | Web9月30日・郵送8月28日消印（要項の時刻まで） |
| 受験手数料 | 8,900円（非課税。Webは事務手数料297円別） |
| 合格基準 | 要項「合格基準」の得点・相対評価の説明 |
| 出題分野 | 5分野（委託契約・会計・維持修繕・適正化法・その他管理事務） |

メモが終わったら「試験日程（令和8年度）」でカレンダー登録し、「学習計画の立て方」で週次時間を割ってからテキスト第1章に入る流れが安全です。

35出題分野の全体像（学習の入口）

管理業務主任者試験の出題は5出題分野です。公式テキストの目次と要項の科目表を並べ、週次計画の「箱」にします。

| 出題分野 | 内容のイメージ |
| --- | --- |
| 委託契約 | 管理委託契約の条項・報酬・業務範囲 |
| 会計 | 管理費・修繕積立金・会計処理・収支報告 |
| 維持修繕 | 長期修繕計画・点検・工事区分 |
| 適正化法 | マンションの管理適正化に関する法律の骨格 |
| その他管理事務 | 総会・管理規約・日常の管理事務 |

マンション管理士試験合格者は適正化法5問が免除され45問となりますが、学習では他4分野の配点を軽視しないでください。2週間で1分野を一周し、演習正答率を記録してから次分野へ移る方法が続きやすいです。

4当サイトでできること

| 機能 | 使い方 |
| --- | --- |

5次に読む記事と学習開始

概要を把握したら、次の順で記事と行動を進めます。

1. 「試験日程（令和8年度）」— 12月6日から逆算したカレンダー
2. 「学習計画の立て方」— 週次時間と5出題分野のローテ
3. 「過去問の使い方」— テキスト先行の演習順
4. 委託契約のテキスト第1章＋分野別演習10問

教材は公式テキスト1冊＋問題集1冊から始め、解き直し時間を確保してから参考書を増やす方が得点に直結します。演習で正答率が上がった論点はミスノートから卒業させ、次の弱点分野に週次時間を回す運用が直前の負荷を抑えます。

6よくある質問

管理業務主任者試験は何を評価する試験ですか？
マンション管理の実務に必要な知識・能力を評価する学科試験です。出題範囲・合格基準・試験方法はマンション管理業協会要項が正本です。50問・120分・5出題分野の科目名と配分は要項の科目表と公式テキスト目次で揃え、体験談の「出題傾向」だけで計画を立てないようにしてください。
令和8年度の試験日と受験手数料はいくらですか？
令和8年度は2026年12月6日（日）13:00〜15:00の実施、受験手数料8,900円（非課税）がマンション管理業協会要項・公式案内で公表されています。Web申込では事務手数料297円（税込）が別途かかります。年度ごとに変わるため、申込前に要項の「試験日程」「受験手数料」を開き、カレンダーには和暦・西暦の両方で登録すると誤登録を防げます。
概要を読んだあと、最初の学習は何から始めますか？
要項メモと試験日程の確認のあと、委託契約のテキスト第1章と分野別演習10問が定番です。5出題分野の目次を1枚に写し、2週間で1分野を一周するペースで正答率を記録してください。過去問大量演習より、テキスト＋演習＋用語の往復を先に固める方が安定します。
