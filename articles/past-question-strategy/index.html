管理業務主任者試験の過去問の使い方（分野別→年度別）

管理業務主任者試験の過去問は、解く順番を誤ると解説を読んでも定着しにくくなります。基本はテキスト先行で、分野別演習で正答率を記録したあと、年度別の通しに移ります。出題は5出題分野から50問、令和8年度試験日は2026年12月6日（日）です。本記事では過去問・模試の段階配分、解き直しの間隔、直前1か月の止め方を表にまとめます。問題数・マン管合格者の45問はマンション管理業協会要項で毎年確認してください。

この記事の要点

本記事を読むと、過去問を学習のどの段階でどの順番で使うべきかの全体像が分かり、学習計画・用語解説と接続できます。

  • テキスト先行
  • 分野別→年度別
  • 50問120分の通し
  • 論点タグ解き直し
  • 直前は解き直し

1過去問戦略の基本（テキスト先行）

過去問戦略の基本はテキスト先行です。条文未読のまま年度別過去問を全問解くと、解説を読んでも定着しにくいです。

| 段階 | 内容 |
| --- | --- |
| 1 | テキスト該当章＋分野別演習10問 |
| 2 | 5出題分野を1周（分野別正答率記録） |
| 3 | 年度別10問（時間計測なし） |
| 4 | 通し模試（50問・120分。マン管合格者は45問） |

独学開始直後は「学習計画の立て方」の週次ルーティンを優先し、過去問大量演習は中盤以降に回すと負荷が安定します。

2分野別→年度別の順番

おすすめの順番は分野別→年度別です。

| 順番 | 目的 |
| --- | --- |
| 分野別 | 委託契約・会計など弱点分野の正答率を可視化 |
| 年度別 | 出題の組み合わせ・最近の論点 |
| 通し | 120分の時間配分・マーク練習 |
| 解き直し | ミス論点の定着 |

5出題分野名はマンション管理業協会要項の科目表と公式テキスト目次で統一します。分野別で50％未満の分野は、新しい年度問を増やす前にテキスト該当章へ戻してください。

3解き直しと論点タグ

過去問の価値は解き直しにあります。

| タイミング | 作業 |
| --- | --- |
| 当日 | 誤答理由（知識・読み落とし・ケアレス） |
| 3日後 | 同論点を3問 |
| 7日後 | 解説を読まずに再挑戦 |
| 14日後 | 説明が1行で言えるか確認 |

論点タグを付けると、50問120分の通し演習で時間が足りなかった分野と弱点復習が接続しやすくなります。誤答語は用語解説で定義を確認してから演習に戻してください。

4模試の時期と本番条件

通し模試は試験日12月6日（日）の6週前以降が目安です。

| 時期 | 内容 |
| --- | --- |
| 6週前〜 | 月1回・50問120分（マン管合格者は45問） |
| 記録 | 得点・未解答数・マークミス |
| 修正 | 弱点2分野に週70％ |
| 参照 | 要項の合格基準・相対評価の説明 |

受験手数料8,900円・申込締切は「試験日程」記事と要項で確認し、模試週と手続きが重ならないようカレンダーを分けます。

5直前1か月と関連記事

直前1か月は新規過去問を止め、解き直し90％に寄せます。

  • ミスノート上位50問の反復
  • 数値・期限は要項とテキストで再確認
  • 「学習計画の立て方」で日曜復習を維持

過去問を解いたあと用語解説へ戻る行動を1セットにすると、単なる量消化になりません。正答率が上がった論点はミスノートから外し、次の弱点に時間を回してください。マンション管理業協会要項で問題数（50問・45問）を再確認してから通しに入ってください。

6よくある質問

最初から年度別の過去問を解いてもよいですか？
テキストと分野別演習が十分でない段階ではおすすめしません。5出題分野の入口を分野別10問×5で一周し、正答率を記録してから年度別10問に入る順が定着しやすいです。どうしても年度問から始めたい場合は、解いた論点をテキスト該当章で必ず裏取りしてください。
過去問は何年分やればよいですか？
年数より解き直しの質が重要です。直近5年分を年度別で回し、同じ論点を2回以上ミスしたらタグを付けて3日・7日・14日後に解き直すサイクルを優先してください。出題範囲の改定はマンション管理業協会要項で確認し、古い年度問だけで論点を判断しないでください。
直前に過去問を増やすべきですか？
直前1か月は新規過去問を増やさず、ミスノートと解き直しに集中する方が効果的なことが多いです。12月6日試験の2週間前は通しより、誤答上位50問の反復と用語・テキスト該当章への往復を優先してください。形式・問題数は要項で再確認し、不安な分野2つに週の時間の70％を配分すると安定します。
