管理業務主任者試験の受験資格

管理業務主任者試験の受験資格は、マンション管理業協会の要項「受験資格」章が唯一の正本です。実務経験・研修受講・学歴など、区分ごとに要件が定められており、過去の体験談だけで判断すると申込ミスにつながります。本記事では該当区分の見つけ方、証明書類の準備、資格確認後の5分野学習の始め方を表に整理します。令和8年度試験日2026年12月6日（日）・手数料8,900円も申込前に要項で確認してください。

この記事の要点

本記事を読むと、自分が管理業務主任者試験のどの受験資格区分に該当するか、必要な実務・研修・書類を申込前に揃えられる手順が分かります。

  • 要項区分表が正本
  • 体験談だけで判断しない
  • 書類は早めに準備
  • 疑問は申込前に問合せ
  • 確認後5分野学習

1受験資格の確認手順

受験資格は試験要項の「受験資格」章が唯一の正本です。区分は年度で細部が改定されることがあるため、最新要項の表を自分の経歴と1行ずつ照合します。

| 手順 | 作業 |
| --- | --- |
| 1 | 要項PDFの受験資格章を印刷または画面で固定 |
| 2 | 学歴・実務・研修・選任歴を年表に書き出す |
| 3 | 区分表で該当行を1つに特定 |
| 4 | 必要書類・証明の発行主体と期限をメモ |
| 5 | 不明点は申込前にマンション管理業協会へ問い合わせ |

非公式サイトの「受験OKリスト」は参考程度にし、数値・区分名・必要期間は必ず要項原文で確認してください。

2区分表の読み方（実務・研修・学歴）

要件は区分ごとに異なります。複数ルートがある場合は、証明しやすい区分を選びます。

| 要素 | 要項で確認すること |
| --- | --- |
| 実務経験 | 対象業務の定義・必要期間・在籍主体 |
| 研修 | 受講科目・実施主体・修了証の要件 |
| 学歴 | 卒業・見込み・専攻の該当有無 |
| その他 | 要項に記載の特例・併用可否 |

日数・年数の計算方法も要項に記載があります。

  • 申込前にメモに起こし
  • 社内人事・法務と共有すると
  • 後から書類不備で困るリスクを減らせ

3申込前チェックリスト

手数料8,900円を支払う前に、次を済ませます。

| 項目 | 確認 |
| --- | --- |
| 資格区分 | 要項表と経歴が一致 |
| 証明書類 | 発行に2週間以上かかるものは先に依頼 |
| 試験日 | 2026年12月6日（日）— 要項で再確認 |
| 申込締切 | Web9月30日・郵送8月28日消印（要項の時刻まで） |
| 写真・決済 | Web申込の規格・事務手数料297円（税込）別 |
| 5問免除 | マン管合格者は証明書類の期限を別途確認 |

資格不明のまま決済すると、受験無効となるおそれがあります。疑問点は回答を記録してから申込し、「試験日程」記事でカレンダーも登録してください。

4資格確認後の学習開始

要件を満たすと判断できたら、並行して学習を始められます。

  • 5分野目次を公式テキストで1枚に写す
  • 適正化法または委託契約第1章＋分野別演習
  • 2週間ごとに分野別正答率を記録
  • 「学習計画の立て方」で12月6日から逆算

実務経験者は現場用語に馴染みやすい一方、条文・数値は演習と解き直しが必要です。資格確認と学習を切り分け、申込締切の2週間前までに演習習慣をつけると安心です。

5よくある誤解

受験資格まわりで混同しやすい点です。

| 誤解 | 正しい確認先 |
| --- | --- |
| 未経験だから受験不可 | 要項区分表で複数ルートを確認 |
| 前年度の体験談がそのまま使える | 最新要項の表で上書き |
| マン管試験合格＝管業試験不要 | 別試験。免除は5問のみ（要項確認） |
| 社内説明が要項より優先 | 要項・マンション管理業協会確認が優先 |

「受験資格の確認」が終わったら「試験概要」「学習計画」へ進み、5分野を2週間で1分野ずつ回すペースで演習量を増やしてください。

6よくある質問

受験資格はどこで確認すればよいですか？
一般社団法人マンション管理業協会が公表する最新受験要項が正本です。区分表・必要書類・提出期限を通しで読み、自分の経歴と1項目ずつ照合してください。非公式まとめは参考程度にし、数値・区分名は要項原文で必ず確認します。疑問点は申込前に問い合わせ、回答をメモしてから手続きに進んでください。
実務経験が短くても受験できますか？
要件は区分ごとに定められています。管理業務の在籍期間・研修・学歴など、複数ルートがある場合は証明しやすい区分を選びます。日数・年数の計算方法も要項に記載があるため、申込前に年表メモを作り、不明点はマンション管理業協会へ問い合わせてから手続きしてください。
資格不明のまま申し込むとどうなりますか？
受験資格を満たさないまま申込・受験した場合、無効となるおそれがあります。疑問点は申込前にマンション管理業協会へ問い合わせ、回答を記録してから決済してください。社内の人事・法務と要件を共有すると、書類不備による申込遅延も防げます。資格確認後は分野別演習から学習を始め、申込と並行して得点力を育ててください。
