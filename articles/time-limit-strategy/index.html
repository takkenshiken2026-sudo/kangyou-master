管理業務主任者試験の時間配分（50問120分の戦略）

管理業務主任者試験は50問・120分（マン管士合格者は45問・120分）のマークシート試験です。全問に均等に時間を使うより、「取れる問題を落とさない」配分の方が得点に効くことが多いです。令和8年度の試験日は2026年12月6日（日）13:00〜15:00、問題数・合格基準はマンション管理業協会の要項が正本です。本記事では1問あたり約2分24秒（50問）または約2分40秒（45問）の目安、得意分野を先に固める順番、見直し10％の確保、模試での固定手順を表にまとめます。数字は年度で変わるため、直前に要項PDFで上書き確認してください。

この記事の要点

本記事を読むと、本番で時間切れせず得点を最大化する時間配分と、模試で配分を固定する記録の付け方が分かります。

  • 50問120分が標準
  • 1問約2分24秒目安
  • 見直し10％確保
  • 難問3分上限
  • 模試で配分固定

1時間配分の前提（要項の数字）

時間戦略の前提は、要項の問題数と試験時間です。

| 区分 | 問題数 | 試験時間 | 1問目安（計算例） |
| --- | --- | --- | --- |
| 通常 | 50問 | 120分 | 約2分24秒 |
| 5問免除 | 45問 | 120分 | 約2分40秒 |
| 形式 | 4肢択一・マークシート | 13:00〜15:00（令和8年度例） | 要項で再確認 |
| 見直し枠 | — | 総時間の10％前後（約12分） | 模試で先に確保 |

合格基準の得点は要項の相対評価等で決まるため、ここでは「時間切れを防ぐ配分」に焦点を当てます。

25出題分野別の所要時間の記録

分野ごとに時間がかかるかは、模試後の記録で可視化します。

| 出題分野 | 記録する項目 |
| --- | --- |
| 委託契約・会計 | 所要時間・正答率・ケアレス有無 |
| 維持修繕・その他 | 計算ミス・読み落としの分類 |
| 適正化法 | 45問受験者は出題なし（学習のみ） |
| 弱点 | 時間切れ率20％超なら演習量を増やす |

配点の議論より、自分のミスデータと時間切れデータを優先してください。分野の全体像は「5出題分野と学習配分」、演習の進め方は「過去問の使い方」と併読すると一貫します。

3取れる問題優先の進め方

本番は「読み切れる設問・得意分野」を先に固めます。

| 優先 | 後回し |
| --- | --- |
| 条文数値が整理できる設問 | 3分超で張り付く難問 |
| 印を付けて先へ進む | 最初から全問完答 |
| 見直し12分の確保 | 終盤の新解法に挑戦 |
| ケアレス・未記入の確認 | 知識不足分野の深追い（学習期間中） |

難問は3分上限で印を付け、見直し時間で再挑戦するルールを直前演習で3回以上固定してください。

4本番配分例（50問・要項確認）

以下は50問120分の配分一例です（45問の場合は問題数に合わせて調整）。

| 区間 | 時間の目安 |
| --- | --- |
| 前半25問 | 全体の55〜60％（約66〜72分） |
| 後半25問 | 全体の30〜35％（約36〜42分） |
| 見直し | 10〜12分 |
| 1問上限 | 約2分24秒（難問は3分で印） |

得意2分野を前半に寄せ、時間切れが多い分野は学習期間中に演習量を20％増やします。誤答理由を知識不足・読み落とし・ケアレスに分類し、同タイプを1週間後に解き直すと定着しやすくなります。

5時間配分で混同しやすい点

- ### 45問だから余裕があるわけではない
120分は同じため
- 1問あたりの目安はやや伸びますが
- 他4分野の出題密度は下がりません

45問模試で練習してください。

マン管士試験の時間配分を流用しない

マン管士は7分野・別問題数・別時間のことが多く、管業の50問120分の型は要項ベースで別管理してください。

演習で時間計測しない

知識があっても本番で時間切れになる場合があります。月1回は必ず120分計測の通し演習を入れてください。

見直しを最後の5分だけにしない

マークシートの記入ミス確認には10分以上あると安全です。模試から見直し枠を確保する習慣をつけてください。

6よくある質問

50問120分では1問何分を目安にすればよいですか？
単純計算では120分÷50問＝約2分24秒です。ただし読み込みの長い設問では3分を超えることがあるため、難問は印を付けて先に進み、見直し時間で再挑戦するルールが有効です。45問120分の場合は約2分40秒が目安になります。問題数はマンション管理業協会の要項で毎年確認してください。
時間が足りない分野は学習でどう直しますか？
模試後24時間以内に「時間切れになった分野」を1行で記録し、翌週の演習配分をその分野に20％寄せます。知識不足と時間不足は別管理で、知識不足はテキスト該当章＋分野別演習、時間不足は通し模試の頻度を増やしてください。記入ミスが多い場合は「マークシート対策」記事の手順も併用してください。
直前1か月の時間配分はどう変えますか？
新規年度の過去問追加は試験4週前で止め、解き直しと通し模試（50問または45問・120分）に週の時間の大半を使います。配分ルール（前半60％・見直し10％）は変えず、弱点2分野のミスノートから優先して解き直してください。試験日12月6日（日）の2週間前からは睡眠7時間を最優先にし、長時間の初見問題集には手を出さない運用がおすすめです。
