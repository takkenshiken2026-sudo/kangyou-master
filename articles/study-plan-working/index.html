管理業務主任者試験の社会人向け学習計画（働きながら）

管理業務主任者試験を仕事しながら受ける社会人は、「毎日3時間」より「週9時間を8か月続ける」設計が現実的です。令和8年度は試験日2026年12月6日（日）、50問・120分・5出題分野、受験手数料8,900円（非課税・要項で再確認）です。本記事では5出題分野の月2重点、通勤演習＋平日夜60分＋休日3時間の型、繁忙期の調整と直前2か月の巻き返しを表にまとめます。正本は一般社団法人マンション管理業協会（https://www.mankan.or.jp/）の要項であり、申込締切と学習はカレンダーを分けると直前の焦りが減ります。

この記事の要点

本記事を読むと、仕事しながら管業試験に合格するための月次・週次計画と、挫折しにくい時間の型が分かります。

  • 週9時間×8か月
  • 月2分野重点
  • 日曜は解き直し
  • 繁忙期は週5時間
  • 12月6日から逆算

1全体像を5出題分野に分ける

社会人計画は「週の総時間」より「毎日触れる」が重要です。マンション管理業協会要項の出題範囲と公式テキスト目次を1枚に写し、5出題分野のうち月2分野だけに絞ります。

| 月 | 重点分野の例（要項・目次で調整） |
| --- | --- |
| 1〜2 | 委託契約＋会計 |
| 3〜4 | 維持修繕＋適正化法 |
| 5〜6 | その他管理事務＋通し演習 |
| 7〜8 | 弱点2分野＋解き直し中心 |

全部同時に追うと仕事後に挫折しやすいため、「今月は2分野だけ」をカレンダーに大きく書いてください。試験日12月6日（日）と手数料8,900円は手続き用カレンダーに分離します。

2学習期間の目安

社会人の目安は8〜10か月・週8〜10時間です。残業が多い月は週5時間でも計画を継続し、ゼロにしないことが重要です。

| 週あたり時間 | 期間の目安 |
| --- | --- |
| 週9時間 | 9〜10か月（本記事の標準） |
| 週5時間 | 12か月以上を見込む |
| 試験2か月前 | 週12時間へ一時増強 |

  • 令和8年度試験日12月6日（日）から逆算し
  • 繁忙期（決算・引渡し等）はカレンダーにマークし
  • その週は解き直しのみに切り替える計画も有効

マン管合格者は45問・120分のため、通し演習の問題数を要項どおりに統一してください。

3週間スケジュールの例

週9時間の社会人例です（2週間試して自分用に調整）。

| 枠 | 内容 | 目安時間 |
| --- | --- | --- |
| 通勤 | 演習または用語10問 | 往復30分 |
| 平日夜 | 演習5問＋用語5語 | 60分×5日 |
| 土 | テキスト該当章1章 | 2時間 |
| 日 | 週のミス題解き直し | 2.5時間 |

出張週は解き直し10問のみでも可。完璧に守れなくても、週合計7時間以上を4週連続で維持できれば前進です。詳細な型は「独学の週間・月間スケジュール」記事と照らし合わせてください。

4復習日の入れ方

日曜午前を復習日に固定します。社会人は平日の疲労で新規が入らない日があっても、日曜だけは解き直しを守ると週次計画の錨になります。

  • 復習日は新規章を開かず、今週のミス演習＋用語10語
  • 誤答理由を3分類（知識不足・読み落とし・ケアレス）
  • 同タイプを3日後・1週間後に再テスト
  • 正解できた問題数を週次で数え、小さな達成にする

復習比率の目安は新規インプット60％・解き直し40％。正答率が伸びない週は新規を止め、日曜2時間だけでも継続してください。

5直前期の調整

直前1か月は残業調整と学習の絞り込みが中心です。

1. 新規章のインプットを止める
2. 弱点2分野に週の時間70％
3. 50問（または45問）120分の通し演習を月2回
4. 試験前週に有休0.5〜1日（会場・持ち物・軽い解き直し）
5. 「仕事と勉強の両立」記事の繁忙期ルールを再確認

12月6日（日）13:00〜15:00の当日は、スケジュールより体調・受験票・マークシートの見直し時間を優先してください。申込・手数料はマンション管理業協会要項で試験2週間前までに再確認します。

6よくある質問

社会人は1日何時間勉強すればよいですか？
週合計9時間前後を目安に、平日朝30分＋夜60分・休日集中の型が続きやすいです。まず2週間、実際に確保できた時間を記録し、無理な計画は早めに下げてください。5出題分野は月2分野重点に回し、正答率が伸びない分野は解き直し比率を上げます。試験日・手数料8,900円はマンション管理業協会要項で必ず上書き確認してください。
繁忙期に学習が止まった週はどうすればよいですか？
翌週ゼロにせず、週5時間＋日曜2時間の解き直しだけでも継続してください。新規インプットを止め、ミスノートと用語10語に絞ると負荷が下がります。試験2か月前に週12時間へ一時増強する計画を、あらかじめカレンダーに書いておくと巻き返しやすいです。12月6日試験日から逆算し、直前は解き直し中心に切り替えてください。
社会人向け計画と独学スケジュールの違いは？
本記事は月次・週9時間の全体像、「独学の週間・月間スケジュール」は平日・休日の時間配分の詳細です。まず2週間の実学習時間を記録し、週間型を決めてから8か月表に当てはめると現実的です。通信講座がなくても、正答率記録と日曜復習で十分運用できます。50問・120分の本番条件は要項と過去問の使い方記事で揃えてください。
