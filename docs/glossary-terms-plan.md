- 試験で**頻出する重要語**を優先し、10分野を**幅広くカバー**する

## 重要度

| ラベル | 基準 |
|--------|------|
| **A** | 過去問・一問一答で繰り返し登場、または条文・数値の核 |
| **B** | 関連論点・比較対象として必要 |

## 作業フロー

```bash
# 1. 用語 CSV 生成（tools/populate_kangyou_glossary_terms.py の CORE を編集）
python3 tools/populate_kangyou_glossary_terms.py

# 2. ビルド・検証
python3 tools/build_all.py

# 3. デプロイ（Actions 設定後は push のみ / 現状は deploy_gh_pages.sh）
bash tools/deploy_gh_pages.sh
```

## 第3フェーズ（400語以上）

1. 各用語ページの本文を試験向けに肉付け（テンプレ短文から一次情報ベースへ）
2. 問題 CSV の `tags` / 解説から `term:` リンクを増やす
3. 判例名・数値論点を個別用語として追加

## 正本

- データ: `data/glossary_terms.csv`
- 生成: `tools/build_glossary_pages.py` → `terms/g-*.html`, `terms/index.html`
- 一覧 UI: `site-terms-index.js`（`shortDef || definition`）
